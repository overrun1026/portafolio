FINORA · FINANZAS PERSONALES
03 BACKEND · API REST

Finora — Gestor de Finanzas Personales

Aplicación web para organizar y controlar las finanzas personales. Permite gestionar ingresos y gastos, administrar presupuestos, crear metas de ahorro y consultar informes financieros. Docker Compose facilita la ejecución conjunta del backend, la base de datos y el frontend.
